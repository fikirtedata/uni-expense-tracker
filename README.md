# 💰 Uni Expense Tracker

A lightweight, secure web application built with Django to help university students and peers track their daily expenses, manage budgets, and monitor financial activity. 

🔗 **Live Demo:** [https://uni-expense-tracker.onrender.com](https://uni-expense-tracker.onrender.com)

---

## ✨ Features
* **User Authentication:** Secure login and session management powered by Django's built-in auth system.
* **Expense Management:** Add, view, and organize daily transactions and categories.
* **Budget Tracking:** Keep tabs on spending limits and financial goals.
* **Cloud Deployment:** Hosted live on Render with WhiteNoise handling static assets.

---

## 🛠️ Tech Stack
* **Backend:** Python, Django
* **Database:** SQLite (Development & Lightweight Production)
* **Styling:** HTML, CSS
* **Deployment:** Render (Free Tier), Gunicorn, WhiteNoise
